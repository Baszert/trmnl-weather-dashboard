# Weather Dashboard

Yet another weather dashboard, with dot-matrix style numbers: current temperature, today's high/low, condition icons and a short forecast.

<a href="https://trmnl.com/recipes/191027"><img width="150" alt="Works with TRMNL" src="https://trmnl.com/images/brand/badges/light/works-with-trmnl/trmnl-badge-works-with-light.svg" /></a>

## Settings
Location name, latitude/longitude, temperature unit (°C / °F) and color mode (dark / light).

Data from [Open-Meteo](https://open-meteo.com/). Icons by [Weather Icons](https://github.com/erikflowers/weather-icons). Thanks Maximillian for the improved 3 and 8 digits.

### Develop locally

Templates and settings live in [`src/`](src/), ready for [trmnlp](https://github.com/usetrmnl/trmnlp):

```sh
gem install trmnl_preview
trmnlp serve
```
